# vitalnexus-site

Static marketing site for VitalNexus, which builds business automation, AI assistants, and data systems for small and mid-sized businesses.

## Run locally

It's a single self-contained `index.html` with no build step. Open it in a browser, or serve the folder:

```sh
npx serve .
```

## Contributing

Make all changes on a branch and open a pull request. Don't push to `main` directly.
